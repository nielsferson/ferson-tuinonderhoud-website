# Ferson Tuinonderhoud

Website voor Ferson Tuinonderhoud – tuinonderhoud in België.

## Structuur

- `src/pages` – de pagina's (Home, Diensten, Over ons, Contact)
- `src/components` – herbruikbare onderdelen (Navbar, Footer, Card, ...)
- `src/assets/images` – afbeeldingen
- `src/styles` – CSS
- `src/hooks` – custom React hooks
- `src/utils` – hulpfuncties

## Starten

npm install
npm run dev
